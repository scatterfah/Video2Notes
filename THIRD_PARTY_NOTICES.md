# Third-party software

Video2Notes uses the following open-source projects. Each keeps its own license.

- yt-dlp (Unlicense): https://github.com/yt-dlp/yt-dlp
- OpenCV (Apache 2.0): https://opencv.org
- ReportLab (BSD): https://www.reportlab.com
- Pillow (HPND): https://python-pillow.org
- tqdm (MPL 2.0 / MIT): https://github.com/tqdm/tqdm
- Deno (MIT), bundled in the Windows installer: https://deno.com
- FFmpeg (LGPL build), bundled in the Windows installer as a separate
  ffmpeg.exe file: https://ffmpeg.org
  Builds: https://github.com/BtbN/FFmpeg-Builds
